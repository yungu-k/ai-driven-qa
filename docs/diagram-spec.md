# 블로그 도해 공용 규격 v1 (draft)

작성: 디자이너 세션, 2026-09-07. 위치는 tw와 합의 전 — 이 파일이 정본 후보다.
적용 대상: 글 본문에 들어가는 설명 도해(다이어그램). 스크린샷·차트 캡처는 해당 없음.

## 1. 산출물 형식

- **SVG 라이트/다크 2종 페어**. 파일명 `<post-slug>-<figure-name>-light.svg` / `-dark.svg`
- 위치: `public/images/diagrams/` (블로그 저장소에만 둔다 — 사내 git에 블로그 재료 금지)
- 두 변형은 **단일 소스에서 생성**한다(토큰 치환). 소스·생성 스크립트는 `docs/diagram-src/`.
  손으로 두 벌 관리하면 반드시 드리프트한다.

## 2. 왜 2종 페어인가 (결정 기록)

블로그는 라이트/다크 토글이 있다(`data-theme`, FOUC 인라인 스크립트가 항상 light/dark 중 하나를 박음).

- SVG 내부 `prefers-color-scheme` 미디어쿼리 → OS 설정만 따라가고 **사이트 토글과 어긋난다** (기각)
- 인라인 SVG + CSS 변수 → 테마 완벽 추종이지만 마크다운 본문이 비대해지고 **RSS 리더에서 var() 미해석** (기각)
- 단일 고정 배경 도해 → 한쪽 테마에서 이물감 (기각)
- **2종 페어 + CSS 스위칭** → 채택. 비용은 파일 2개 + 아래 CSS 4줄.

### 임베드 규약 (마크다운 본문, raw HTML)

```html
<img class="diagram-light" src="/images/diagrams/repo-record-map-light.svg" alt="…" />
<img class="diagram-dark" src="/images/diagrams/repo-record-map-dark.svg" alt="…" />
```

### CSS 헬퍼 (typography.css 등 전역에 1회 추가 필요)

```css
/* 테마별 도해 스위칭 — light/dark 이미지 페어 */
.diagram-dark {
  display: none;
}
html[data-theme="dark"] .diagram-dark {
  display: block;
}
html[data-theme="dark"] .diagram-light {
  display: none;
}
```

기본값이 라이트인 이유: `data-theme` 부착 전 찰나에도 이미지가 이중 표시되지 않게.

## 3. 크기

- 기준 폭 **736px** (본문 프로즈 폭). viewBox는 1x 실치수로 잡는다 — `viewBox="0 0 736 H"`
- 높이 자유. 가로 스크롤 금지 — 736을 넘기지 않는다
- 최소 글자 크기 **12px** (1x 기준). 모바일 축소를 감안해 12 미만 금지

- 의미를 지는 그래픽 오브젝트(윤곽·연결선·아이콘 패스)는 지면 대비 **3:1 이상** — 위 표에서 보조 스트로크·강조·경고만 자격이 있다
- 텍스트는 **4.5:1 이상** (12px 배지 글자 포함 — 굵게 써도 18.7px 미만이면 4.5 기준)
- 색만으로 의미를 구분하지 않는다 — 반드시 형태(실선/점선, 배지, 라벨)를 병행

## 5. 타이포그래피

- 폰트 스택: `"Pretendard Variable", Pretendard, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`
- **주의: `<img>`로 임베드된 SVG는 페이지 웹폰트에 접근하지 못한다.** 실제 렌더는 열람자 시스템 폰트다
  (Windows=Malgun, macOS=Apple SD Gothic Neo, Android=Noto Sans KR). 따라서:
  - 텍스트 폭을 빠듯하게 맞추지 않는다 — 폰트별 자폭 편차 ±10%를 견디는 여백
  - `text-anchor` 명시(middle/start), 긴 라벨은 미리 줄바꿈
- 크기 3단: **15px/700** (요소 제목) · **13px/400** (설명) · **12px/600** (배지·태그)
- 기울임 금지(한글 합성 기울임), 이모지·딩벳 글리프 금지 — 체크·화살표·엑스는 **`<path>`로 그린다**

## 6. 선·형태

- 굵기: **2px** 주요 윤곽·의미 스트로크 · **1.5px** 보조 · **1px** 장식 헤어라인
- 점선 `stroke-dasharray="4 3"` — 의미 고정: **부재·외부·비공식** (없는 것, 경계 밖의 것)
- 화살촉·체크마크는 path로 (5절 글리프 금지와 같은 이유)
- 모서리 반경: 12px 큰 컨테이너 · 8px 카드 · 999px 배지(pill)
- 간격은 8px 그리드

## 7. 내용 규칙

- **내부 식별자 금지**: 회사·고객·제품 컴포넌트 실명, 서버 주소, 실제 경로. 글 본문과 같은 익명화 수준
- 수치는 글 본문의 수치와 일치해야 한다 (도해가 본문과 다른 숫자를 말하면 안 됨)
- `alt` 필수 — 도해가 말하는 결론까지 적는다 (구성 요소 나열로 끝내지 않는다)
- 도해 안에 글 제목·캡션 중복 금지 — 캡션은 본문 몫
